# Client Demo Website

A modern dynamic business website with a public-facing site and an admin panel.

## Project structure

The project will be built step-by-step:

- `client/` — public website
- `admin/` — admin dashboard
- `server/` — backend API and database integration

## Planned features

- Responsive public website
- Services/products management
- Enquiries and bookings
- Admin authentication
- Dashboard analytics
- Content management

## Development

The first step is establishing the project structure. More application code will be added incrementally.
